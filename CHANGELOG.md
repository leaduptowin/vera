## [0.1.0] - 2026-11-02

### Added

- Browser-only real-time meeting workbench.
- Web Speech API continuous Chinese transcription with manual-note fallback.
- Sliding-window, debounced SSE summary stream with adjustable sensitivity.
- Structured core topics, key points, action items and timeline extraction.
- Three-column workstation UI with responsive mobile tabs.
- Selection actions: highlight, extract, delete.
- Manual task CRUD and completion tracking.
- Markdown export, summary clipboard copy.
- Local-only persistence of meetings, transcripts, summaries and task state.
- Seeded example meeting and automatic demo entry.
- Mock SSE transport and real-SSE integration guide.
- GitHub Actions CI and GitHub Pages deployment workflow.
- Open-source repository docs, security/privacy policies and templates.
